# Iron Rabbit — iOS App Store Build Guide

This project is already fully wired for Capacitor iOS. Everything under `/frontend/ios/` is set up. This document is the complete walkthrough of what you need to do **on your Mac** to build, test in the iOS simulator, and submit to the App Store.

Nothing more is needed on the codebase side — all iOS configuration, permission strings, splash, and icon are in place.

## 🛠  Prerequisites on your Mac

1. **Xcode 15+** (from the App Store)
2. **CocoaPods** — install via `sudo gem install cocoapods` or `brew install cocoapods`
3. **Node 18+** and **Yarn** (you already have these locally)
4. **Apple Developer account** (`$99/year`) — enroll at https://developer.apple.com

---

## 🚀 Step-by-step: from source to iOS simulator

Run these on your Mac from the repo root after pulling the latest:

```bash
cd frontend

# 1. Install JS dependencies (one time)
yarn install

# 2. Build the production web bundle
yarn build

# 3. Copy the web build into the iOS project + install CocoaPods
npx cap sync ios

# 4. Open the project in Xcode
npx cap open ios
```

Xcode will now open `frontend/ios/App/App.xcworkspace`. From there:

1. Pick a simulator (top toolbar → e.g. `iPhone 15 Pro`)
2. Press `Cmd + R` to build and run

If pods complain: `cd frontend/ios/App && pod install && cd ..` then re-run `npx cap open ios`.

## 🏪 Step-by-step: submitting to the App Store

### One-time setup

1. Open `App.xcworkspace` in Xcode.
2. Select the **App** target in the left sidebar → **Signing & Capabilities** tab.
3. Set your **Team** (your Apple Developer team).
4. Confirm the **Bundle Identifier** matches what you register in App Store Connect (default: `com.ironrabbit.app`).
5. Under **General** tab → set the **Marketing Version** (visible to users, e.g. `1.0.0`) and **Build** (integer, e.g. `1`) — bump on every submission.

### Every submission

1. Bump **Marketing Version** or **Build** in Xcode → **General** → **Identity**.
2. From the Xcode top bar, pick **Any iOS Device (arm64)** as the target.
3. Menu: **Product → Archive**.
4. When the Organizer opens, click **Distribute App → App Store Connect → Upload**.
5. Follow the prompts. Xcode auto-signs with your Distribution certificate.
6. Wait ~5–15 minutes for App Store Connect to process the build.
7. Go to https://appstoreconnect.apple.com → your app → **TestFlight** or **App Store** → submit for review.

## 🩹 Common gotchas

| Symptom | Fix |
|---|---|
| "No such module 'Capacitor'" | Run `npx cap sync ios` then reopen the workspace |
| Build fails at pod install | `cd frontend/ios/App && pod repo update && pod install` |
| Splash flashes wrong colour | Adjust `SplashScreen.backgroundColor` in `capacitor.config.ts` then `npx cap sync ios` |
| Web changes don't appear in simulator | `yarn build` then `npx cap copy ios` (fastest way to push new web assets without touching pods) |
| Icon looks pixelated | Regenerate with `npx @capacitor/assets generate --iconBackgroundColor '#020617'` from a 1024×1024 source in `frontend/resources/icon.png` |
| Apple asks about export compliance during submission | Already answered — `ITSAppUsesNonExemptEncryption=false` is set in Info.plist |

## 🔄 Updating the app after code changes

```bash
cd frontend
yarn build          # rebuild web bundle
npx cap copy ios    # push web bundle → iOS project (fast, no pod work)
# Then in Xcode: Cmd+R to rerun in simulator, or Product→Archive to submit
```

If you added/removed a Capacitor plugin, run `npx cap sync ios` instead of `copy` so the Podfile gets re-resolved.

## 📱 Optional next steps once you're on the Store

- **App Store screenshots** — Apple requires 6.7" (iPhone 15 Pro Max) and 6.5" (iPhone 11 Pro Max) sets. Take them from the iOS simulator via **File → New Screen Recording** or with Xcode's simulator screenshot button.
- **App Preview video** — 15-30s, MP4, uploaded from App Store Connect.
- **App Privacy manifest** — App Store Connect asks you to declare what data you collect. Iron Rabbit is offline-first with no data collection, so the answer is "Data Not Collected."
- **Universal Links** — if you want `https://ironrabbitapps.com/...` links to open the native app, add an `apple-app-site-association` file to your marketing site.

Good luck with the launch!
