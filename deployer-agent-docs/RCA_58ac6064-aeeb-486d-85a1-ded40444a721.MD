`craco build` runs ESLint in fail-on-error mode, so this compile error aborts the frontend build with exit 1.

## Root cause
In `frontend/src/notes/SettingsModal.jsx`, the "Sync pack colors" block `{onSyncPackColors && ( ... )}` already closes cleanly at **line 425** (`</button>` 423, `</div>` 424, `)}` 425). Immediately after it sat an **orphaned duplicate fragment** (lines 426–430) with no matching opening tags:

```jsx
425:          )}
426:
427:                <ChevronRight className={`w-4 h-4 ${isDark ? "text-slate-500" : "text-gray-400"}`} />
428:              </button>
429:            </div>
430:          )}
```

These stray closing tags unbalance the JSX tree; the parser then can't match the following `<div>` (the new Accordion-effect block) and reports the error at 428:14. Almost certainly a bad merge/duplication left over when the new "Accordion Effect" control was added.

## Fix (verified in eph sandbox)
Delete the orphaned fragment — lines 426–430 (the blank line + the four stray tags) in `frontend/src/notes/SettingsModal.jsx`. After the edit line 425 `)}` flows directly into the `{/* Accordion effect for Tile Packs in grid view */}` block. No other change needed.
